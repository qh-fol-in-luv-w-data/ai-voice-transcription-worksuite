## Mục Đích

## Phạm Vi

Phạm vi bám theo app `voice_app`, frontend `frontend/src`, DocType schema và các tích hợp trong source.

## Đối Tượng Sử Dụng

Các vai trò dự án liên quan: PM/BA/Dev/QA/DevOps/Security/Ops.

## Nội Dung Chi Tiết

| Incident | Symptoms | Checks | Resolution | Escalation |
|---|---|---|---|---|
| App unavailable | 5xx/login fail | `bench status`, logs | restart bench/services | DevOps |
| Queue backlog | processing stuck | workers/Redis queue | scale/restart worker | DevOps |
| STT provider down | STT errors | provider status/logs | switch mode/retry | AI/DevOps |
| Disk full | upload/export fails | file storage usage | cleanup chunks/files | DevOps |
| Auth failure | access denied | Frappe user/session | check roles/session | Admin |
| Security incident | abnormal webhook/API | logs/cache | disable secretless webhook/config | Security |

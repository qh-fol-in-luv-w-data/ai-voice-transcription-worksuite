## Nội Dung Chi Tiết

| Category | Requirement | Current evidence | Status |
|---|---|---|---|
| Performance | Long audio should run async. | `frappe.enqueue(queue='long', timeout=3600/1500)`. | Draft |
| Availability | App depends on Frappe, Redis/queue and external AI services. | Source dependencies. | TODO |
| Scalability | Chunking supports long audio; queue workers scale externally. | `split_audio_by_silence()`. | Draft |
| Security | Authenticated APIs use `allow_guest=False`; CSRF header from frontend. | `frontend/src/api.js`. | Draft |
| Privacy | Audio files saved private during upload; exports may be public. | `save_file(..., is_private=1/0)`. | Needs Review |
| Observability | Frappe error log, realtime progress, `VOICE* Log`. | `ActivityLogger`. | Draft |
| Backup/Recovery | Depends on Frappe site backup. | NOT FOUND dedicated backup config. | TODO |

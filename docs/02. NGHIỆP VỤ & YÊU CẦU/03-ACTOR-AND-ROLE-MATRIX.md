## Nội Dung Chi Tiết

| Actor | Role | Permission | Module access | Data scope | Approval | Restrictions |
|---|---|---|---|---|---|---|
| Authenticated user | End user | Frappe session | SPA/API allow_guest=False | Own `Voice Meeting` in history/download | None found | Guest denied |
| System Manager | Admin | DocType permissions | All DocTypes | Broad admin access | TODO | Must protect secrets |
| External proctoring sender | Webhook client | Optional secret header | `proctoring_webhook` allow_guest=True | Cache by session_id | None | Secret should be configured |
| Worksuite API user/token | Integration principal | Token/session | Employee/Project/Task APIs | External system policy | TODO | Secret value not documented |

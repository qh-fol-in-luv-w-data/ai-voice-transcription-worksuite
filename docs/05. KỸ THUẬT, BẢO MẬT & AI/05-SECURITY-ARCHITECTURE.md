## Nội Dung Chi Tiết

| Asset | Trust boundary | Current controls | Risks |
|---|---|---|---|
| Audio files | Browser -> Frappe storage | Auth, CSRF, private file on upload | Retention TODO |
| Transcript/raw_results | DB | Owner filtering in history | Sensitive content exposure via logs/export |
| Voice embeddings | DB | System Manager DocType permissions | Biometric-sensitive data needs policy |
| API keys/tokens | Settings/env/site_config | Password fields/env lookup | Rotation/least privilege TODO |
| External AI APIs | Server outbound | API keys, HTTPS URL enforcement for embedding remote | Provider data policy TODO |
| Proctoring webhook | External inbound | Optional secret header | If secret unset, endpoint accepts guest payload |

## Mục Đích

Tài liệu hóa threat model cho dự án dựa trên source code hiện tại.

## Phạm Vi

Phạm vi bám theo app `voice_app`, frontend `frontend/src`, DocType schema và các tích hợp trong source.

## Đối Tượng Sử Dụng

Các vai trò dự án liên quan: PM/BA/Dev/QA/DevOps/Security/Ops.

## Nội Dung Chi Tiết

| STRIDE | Asset | Threat scenario | Existing control | Risk | Recommended control | Status |
|---|---|---|---|---|---|---|
| Spoofing | User/session | Attacker calls API as Guest | allow_guest=False | Low | Keep Frappe session hardened | Draft |
| Tampering | Meeting data | User updates others' meeting | `_can_access_meeting` in key flows | Medium | Verify all update endpoints consistently | Needs Review |
| Repudiation | AI actions | User denies action | `VOICE Action Log` | Medium | Ensure every major API logs action | Draft |
| Information disclosure | Audio/transcript | Public export URL leaks | Some exports saved `is_private=0` | High | Review private/public file policy | Open |
| Denial of service | Queue | Large/repeated audio | Chunking, long queue | Medium | Add quota/rate limit | Open |
| Elevation | Settings/secrets | Non-admin reads secrets | System Manager permission | Medium | Audit DocType permissions | Draft |

## Giả Định

- ASSUMPTION: Dự án được triển khai như một Frappe app trong Frappe Bench v15+ theo README hiện tại.
- ASSUMPTION: Các URL môi trường ngoài local cần được đội vận hành xác nhận.
